====================================================================== 1.
PROJECT OVERVIEW
======================================================================

PlantScan AI is an AI-powered plant health assistant.

Planned capabilities: - Plant disease detection - Plant-part
classification - Unknown/out-of-scope detection - Plant Health Score -
Treatment recommendations - Organic solution first - Chemical solution
second - Prevention - Multiple languages - Offline + online mobile
operation - Lightweight/mobile-friendly models -
Low-cost/free/open-source tools where practical

The project is being developed by a four-person team.

======================================================================
2. CORE ARCHITECTURE
======================================================================

DECISION: PlantScan AI uses THREE independent AI models.

1.  Plant-part classifier Determines which plant part is visible.

2.  Disease classifier Identifies the disease/class for supported crops.

3.  Unknown/out-of-scope detector Rejects images that are outside the
    supported PlantScan AI scope.

Initially the project targets approximately 10 major crops.

IMPORTANT: The final crop list and disease class structure are NOT yet
frozen.

High-level pipeline:

User image -> Plant-part classifier -> Disease classifier / unknown
detector -> Prediction + confidence -> Plant Health Score -> Treatment /
prevention recommendation -> Mobile app response

Treatment order: 1. Organic solution 2. Chemical solution 3. Prevention

3. MODEL / RESEARCH DIRECTION
======================================================================

Lightweight transfer-learning approaches were researched, including: -
MobileNetV2 - MobileNetV3 - EfficientNet-B0 - YOLO-based approaches -
Feature embeddings - Euclidean/cosine distance thresholds - MC Dropout -
Ensemble approaches - Saliency-based approaches

A previous tomato experiment used approximately: - 10 classes - 5-fold
cross validation - batch size 32 - up to 100 epochs - Adam optimizer -
best reported fold accuracy around 97.1% - reported average around
94.42% - TensorFlow Lite conversion was explored

IMPORTANT: Those historical experiment results are not automatically the
final PlantScan AI benchmark. The current project uses the cleaner
verified multi-source Dataset v1 and the three-model architecture.
